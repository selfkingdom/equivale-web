# Equivale

Equivale es una aplicación web gratuita que pone importes en perspectiva mediante un conversor económico, un histórico comparativo y un reto diario.

Para una revisión local, abre `index.html` en el navegador. La aplicación es estática y carece de un paso de instalación o compilación. El formulario y la medición usan servicios externos. Consulta [Arquitectura](docs/arquitectura.md) antes de probar esos flujos.
